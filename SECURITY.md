# Security

## Secrets
- No passwords or keys are stored in this repository. All secrets come from environment variables (see `.env.example`).
- Earlier versions of this project (the PHP site) had database and admin credentials committed to the repository. Those credentials must be treated as public: they have been (or must be) changed, and must never be reused.

## Reporting a problem
If you find a security issue, please email the store owner instead of opening a public issue.
